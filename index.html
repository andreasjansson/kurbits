One curve

Every mark, letters included, is the curve θ(u): a swing, an Euler bend, optional pen loops and a spiral eye at either end. A pointed pen swells on down-strokes and thins to a hairline on up-strokes.

One rule

Smaller copies of the curve sprout along it, curling away. Fractal makes each sprout a varied miniature of its parent; smaller generations are sparser, so detail fades out instead of turning to fuzz.

Letters

Every printable ASCII character is a point in the same space: one pen stroke, doubling back where it must, with up to eight corners. The points were found by fitting θ(u) to a single-stroke path of each character. Pick a letter to see its numbers, or All to move every letter at once.

No randomness

The same numbers always draw the same ornament. Counts accept fractions and grow the next element in, so every control sweeps smoothly.

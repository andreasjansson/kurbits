One curve

Every mark is the curve θ(u): a wave with Kinoshita's third harmonic, an Euler-spiral term, smooth curvature pulses that make pen loops, and a log-aesthetic spiral eye at either end. A pointed pen swells only on down-strokes, as in 18th-century round hand; a broad nib is also available. Its width follows a pressure profile and optional sinusoidal scallops; parallel copies of the curve give the echo and the stripes.

One rule

Along each curve grow smaller copies of the same curve, curling away, optionally in mirrored pairs. Low thinning turns them into hairline fringes, straight swelling sprouts become leaflets, and ping-pong, swirl and nest change each generation.

Proportion without stretching

Width, height and aspect never scale the drawing. They add scrolls: each arm continues into further full-size scrolls, outward for width and upward for height, alternating sides like a running scroll. The count is continuous, and the generator solves for it so the ornament fills the requested box, from 1:1 to about 12:1.

One root

Stems, an answering counter-curve, chains and a mirrored twin all grow from the same root, so the result is always one connected shape. Symmetry lets the twin drift continuously away from an exact mirror. Width, height and rotation act on the growth, so curves are re-grown rather than distorted.

Self-similar, never identical

Sprouts, chained scrolls and every fractal generation are the same curve again, varied by Q(t) = sin t + 0.7 sin(φt + 1.1) + 0.5 sin((1+√2)t + 2.3). Its frequencies are incommensurate, so the variation is deterministic but never repeats. Drift morphs each generation; varPhase slides the variation along.

Counts that slide

Sprouts, stems, rows, copies, repeats and nest levels accept fractions: 3.4 sprouts means three, with a fourth growing in. That is why every parameter animates without jumps.
